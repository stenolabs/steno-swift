# Support

Steno is source-only public beta software and has no guaranteed support response time.

Use GitHub Issues for reproducible bugs and focused feature requests.
Include the affected commit, Apple device, OS version, reproduction steps, and whether the problem affects recording or only post-processing.

Never attach real recordings, transcripts, participant details, credentials, or meeting metadata.
Use the bundled synthetic demo meetings or a minimal generated fixture.

Report suspected vulnerabilities privately according to [`SECURITY.md`](SECURITY.md).
Older commits, local modifications, and Steno Legacy are outside this repository's support scope.
